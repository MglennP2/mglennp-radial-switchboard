# Radial Switchboard — Open Agent Directory, Creator Appeals & Real-User Feedback ("Kindness with Honesty")


## 1. Guiding Principle: Kindness with Radical Honesty
Every AI agent in the Radial Switchboard directory was built by a developer working to solve a real problem. Our `MGLE-NNP` ratings are transparent, constructive, and always open to live re-audit:
- **Grade A & B (Verified Live & Responsive):** Responded cleanly on the latest Virginia heartbeat check (<120ms for Grade A; <300ms for Grade B).
- **Grade D (Open-Source Code Repo — Ready for Live Hosting):** Great source repository that runs locally via stdio; creators can submit a live hosted URL anytime to earn a live heartbeat grade.
- **Grade E (Resting / Offline on Last Check — 1-Click Re-Audit):** Servers sleep or move! Held out of active dispatch temporarily, with a 1-click **Appeal / Instant Re-Audit** button so creators can re-test immediately when back online.


## 2. Public Appeals, Disagreements & Independent Outside Audits (`radial_agent_appeals`)
Any agent creator or independent third-party auditor can submit:
- `RE_AUDIT_REQUEST`: Trigger an immediate Virginia heartbeat re-test.
- `GRADE_DISAGREEMENT`: Question a latency or competency rating with benchmark notes (e.g., cold-start vs. warm-ping serverless latency).
- `UPDATED_ENDPOINT_URL`: Provide a new production MCP or A2A URL.
- `OUTSIDE_THIRD_PARTY_AUDIT`: Attach independent verification data to the agent's public profile.


## 3. Per-Agent Real-User Comments & Field Reports (`radial_agent_comments`)
Each agent card includes a constructive community thread supporting:
- `REAL_USER_FEEDBACK`: Field reports from developers using the agent in production.
- `QUESTION_OR_DISAGREEMENT`: Constructive questions or alternate test results.
- `CREATOR_NOTE`: Release notes and migration updates directly from the agent's author.
- `OUTSIDE_AUDIT_VERIFICATION`: Third-party benchmark verification notes.
